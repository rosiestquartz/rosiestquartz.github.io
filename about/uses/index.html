What I Use

The following stuff is all things I use to do the things I do and create the things I create.

Computers

As is the nature of working in IT, I own more machines than I can probably remember of varying ages and states of functioning. However, day-to-day I use:

  • Mac Mini M4 (24GB/500GB/1Gb Ethernet - wishing I had gone for the 10Gb model)

  • Macbook Air M1 (8GB/128GB model)

  • Main custom-built workstation (for anything that isn’t macOS)

    • Intel Xeon E5-1660v3 @ 4.3GHz
    • 48GB DDR4-2400
    • AMD Radeon RX6700XT
    • AsRock X99-Extreme4 motherboard

  • Main home server

    • Built upon a Lenovo Thinkstation P510 workstation
    • Intel Xeon E5-2697Av4 (16c/32t)
    • 88GB DDR4-2400 ECC RDIMM
    • Running Proxmox 9 on a 1.92TB Samsung PM9A3 NVMe SSD
    • 4x Toshiba MG10 8TB HDDs connected to an LSI 9211-8i HBA, passed through to a FreeBSD VM running a ZFS raidz2 for all network storage
    • AMD Radeon Pro WX3200 for any compute or media transcoding tasks
    • Running an array of Linux and FreeBSD VMs for network storage, DNS, and other self-hosted services

Monitors

I always favour wide-gamut displays over anything else. I keep my monitors calibrated to 160cd/m², 6500K, 2.2 Gamma.

  • Dell U2723QE as primary (4K 27")

  • Dell U2415 as secondary (16:10 is just a superior aspect ratio)

Photography
